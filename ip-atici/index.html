İP ATICI

Tavanlara ve bloklara ip fırlat, sallan, bırak ve uç!
Lavlara düşmeden olabildiğince ileri git.

🖱️ Tıkla / dokun ve basılı tut → o yöne ip at
👉 Basılı tutarken sağa / sola kaydır → o yöne sallan
⬆️ Soldaki ▲ ÇEK butonuna basılı tut → ip kısalır, kendini çekersin
⬇️ ▼ UZAT butonuna basılı tut → ip uzar, aşağı inersin
     (klavye: Shift / E kısalt, S / ↓ uzat)
✋ Bırak → ipi bırak, havada süzül
⌨️ Boşluk / W / ↑ → otomatik nişanla ip at
↔️ A / D / ← → → sallanmayı güçlendir
🪙 Altınları topla: her biri +10 puan
Süreli güçlendiriciler: 🧲 Mıknatıs → yakındaki altınlar sana uçar (10 sn)
🚀 Roket çanta → ileri uçurur; basılı tutup parmağınla yukarı/aşağı yönlendir (W/S) (5 sn)
👟 Yapışkan ayakkabı → blokların altında baş aşağı yürü (12 sn)
Dikkat: 🔫 Taretler sarkıtlardan sana ateş eder. Kırmızı yanıp sönünce kaç!
     Tarete çarparsan kırılır: +3 🪙

Lava düştün! 🔥
