# Gravity

HTML5 sürümü. `index.html` dosyasını tarayıcıda açarak ya da bir web sunucusundan (ör. GitHub Pages) oynanır.

- `assets/` — oyunun görselleri. Astronot, robot, canavar, gezegen, patlama, eşya ve arayüz görselleri Unity projesinden aktarıldı.
- `assets/ufo.webp` — Microsoft Fluent Emoji 3D (MIT), bkz. `assets/LICENSE-fluent-emoji.txt`.
- `assets/cargo.webp` — bu oyun için çizildi.
- ⚙ paneli (T tuşu) oyun ayarlarını canlı değiştirir; ayarlar ve ilerleme tarayıcıda (localStorage) saklanır.
